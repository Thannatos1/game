Se nenhum ID aparecer, abra o Last Orbit uma vez neste aparelho e volte a esta página. Sem o anon_id, não conseguimos localizar eventos específicos porque não coletamos nome, e-mail ou ID de publicidade.

O que será excluído

  • Eventos de sessão e de partidas vinculados ao anon_id.
  • Pontuações, duração das partidas, capturas, combos e sinais antifraude enviados nesses eventos.
  • Registros de diagnóstico vinculados ao mesmo identificador, quando existirem.

Concluímos a exclusão em até 30 dias e confirmamos pelo e-mail usado na solicitação. Estatísticas já agregadas e que não permitem identificar o anon_id podem ser mantidas.

Excluir dados locais

No Android, acesse Configurações → Apps → Last Orbit → Armazenamento → Limpar dados. Desinstalar o app também remove recordes e preferências locais. Isso não apaga eventos já enviados ao servidor; para isso, envie a solicitação antes de limpar os dados.

Data deletion

Last Orbit does not require an account. Gameplay telemetry is associated only with a random anon_id.

Delete server data

  1. Open this page on the same device and browser used to play.
  2. Copy the anonymous identifier shown above.
  3. Select “Request by email” and send the prepared message to lastorbit.contato@gmail.com.

We delete session, gameplay, score, diagnostic, and anti-fraud events linked to that identifier within 30 days. Aggregated statistics that can no longer identify the anon_id may be retained.

Delete local data

On Android, go to Settings → Apps → Last Orbit → Storage → Clear data. Uninstalling the app also removes local records and preferences. This does not delete events already sent to the server, so submit the server deletion request before clearing local data.
